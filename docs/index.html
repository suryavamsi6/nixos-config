THE CONFIGURATION

Three targets.

Flake outputs compose small, focused modules into complete operating-system configurations.

01 · PRIMARY

NixOS / Hyprland

A Wayland-first daily driver with Ghostty, Quickshell, declarative hardware, gaming, and work tooling.

02 · ALTERNATIVE

NixOS / GNOME

A conventional GNOME session built from the same reusable system and Home Manager layers.

03 · MOBILE

nix-darwin / macOS

A MacBook Air configuration that keeps shell, development, and user preferences portable.

START HERE

Bring it up.

Clone the flake, choose a target, and let Nix do the rest.

$ git clone https://github.com/suryavamsi6/nixos-config.git
$ cd nixos-config

$ nh os switch                         # Hyprland
$ sudo nixos-rebuild switch --flake .#plasma
$ nix run nix-darwin -- switch --flake .#macbook-air

Small modules, clear boundaries

System and Home Manager layers stay separate until the host composes them.

Upstream where possible

Focused build-time patches instead of unnecessary forks.

Safe by default

Secrets stay out of the flake and destructive workflows stay deliberate.

Made for the actual machine

Reliability choices follow the hardware and how it is used every day.
