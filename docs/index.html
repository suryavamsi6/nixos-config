Bring it up.

Clone the flake, choose a target, and let Nix do the rest.

git clone https://github.com/suryavamsi6/nixos-config.git
cd nixos-config

# Primary Linux host
nh os switch

# Alternate Linux host
sudo nixos-rebuild switch --flake .#plasma

# MacBook Air
nix run nix-darwin -- switch --flake .#macbook-air

Small modules, clear boundaries

System configuration and Home Manager configuration stay separate until the host composes them.

Upstream where possible

Use inputs and focused build-time patches instead of maintaining unnecessary forks.

Safe by default

Secrets stay out of the flake, and destructive hardware workflows require deliberate checks.

Made for the actual machine

Performance and reliability choices follow the hardware and the way it is used every day.
